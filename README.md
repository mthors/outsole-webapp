# Outsole Catalog & Digital Showcase

A modern B2B outsole catalog and digital product showcase.

## Tech Stack

- React
- TypeScript
- TanStack Start
- Vite
- Tailwind CSS
- Supabase
- Bun

## Features

- Product catalog
- Product search and filtering
- Product detail pages
- Product images
- Featured products
- Sample request form
- Supabase database and storage
